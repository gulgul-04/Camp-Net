# Socialist Campus Net

A decentralized, peer-to-peer social media platform built for college campuses. 

## Vision
To create a resilient, zero-trust network where students can share resources, code, art, and discussions without relying on centralized servers. Data lives within the network, and participation is driven by local reputation and cryptographic identity.

## Core Technologies
* **GUN.js**: Real-time decentralized graph database for state sync and messaging.
* **SEA**: Security, Encryption, Authorization for key-pair generation (no passwords).
* **IPFS** (Planned): For heavy asset distribution.

## Current Features
* Local cryptographic key generation.
* Secure, serverless authentication in the browser.
